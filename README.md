# 🎬 Video Uniquizer Pro

> Сучасний десктопний інструмент на Python для глибокої унікалізації медіаконтенту з метою обходу автоматичних алгоритмів виявлення дублікатів (Shadowban/Reupload Detection) у TikTok, Instagram Reels та YouTube Shorts.

---

## 🚀 Основні можливості

* **Повна зміна цифрового відбитка (Хешу):** Модифікація кожного пікселя та байта файлу без втрати візуальної якості для глядача.
* **Мікрозміна швидкості та таймінгу:** Плавне коригування кадрів (`setpts`) зі збереженням тональності звуку (`atempo`).
* **Динамічний цифровий шум:** Накладання непомітної для ока зернистості, що повністю руйнує покадрове порівняння.
* **Очищення метаданих:** Повне затирання EXIF-тегів, інформації про пристрій та софт для монтажу.
* **Преміальний GUI:** Сучасний графічний інтерфейс у темному стилі (CustomTkinter) із гнучким вибором файлів та кастомним діалогом збереження.

---

## 🛠 Технологічний стек

* **Мова:** Python 3.10+
* **Движок обробки медіа:** FFmpeg (Subprocess)
* **Інтерфейс (GUI):** CustomTkinter
